# SentinelAI demo cheat sheet

1. Start the backend: `uvicorn backend.app.main:app --reload`
2. Start the dashboard: `streamlit run dashboard/app.py`
3. Click **Submit incident** with the prefilled sample.
4. Analyze → Generate patch → Validate → Approve.
5. Confirm the original `sample_app/buggy_app.py` file is unchanged.
